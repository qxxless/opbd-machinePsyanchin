# Прогноз стоимости недвижимости

Учебный проект по анализу объявлений о недвижимости в Турции и прогнозированию цены с помощью регрессионных моделей. В приложении используется сохранённый Pipeline LightGBM; интерфейс построен на Streamlit.

## Состав папки

- `real_estate_20_test.ipynb` — анализ данных, подготовка признаков, сравнение моделей и оценка на 20 тестовых объектах.
- `real_estate_data_ru_FINAL2.csv` — набор данных для ноутбука и приложения.
- `test_real_estate_samples_ru.csv` — 20 учебных тестовых объявлений.
- `result_real_estate_samples.xls` — приложенный исходный файл результата, сохранённый без изменений.
- `app/app.py` — приложение Streamlit.
- `app/model/model.pkl` — сохранённая модель.
- `app/requirements.txt` — зависимости приложения и ноутбука.
- `screenshots/` — снимки интерфейса; они также вставлены в конец ноутбука.

Файлы с расширением `.xls`, приложенные к работе, фактически содержат CSV-текст. Они сохранены в исходном виде. Ноутбук формирует корректно названный файл `result_real_estate_samples.csv`.

## Запуск приложения в Windows

Откройте PowerShell в корне папки проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r app\requirements.txt
streamlit run app\app.py
```

Приложение откроется в браузере. В разделе «Прогноз» можно задать параметры объекта и получить ориентировочную стоимость; раздел «Дашборд» показывает аналитику объявлений.

## Работа с ноутбуком

Откройте `real_estate_20_test.ipynb` в Jupyter или VS Code. Запускайте его с корня этой папки, чтобы рядом были CSV-файлы и подкаталог `app/model`. Если сохранённая модель уже есть, ноутбук загрузит её; при её отсутствии финальная ячейка обучения создаст модель для приложения.

## Ограничение результатов

Тестовые объекты и их фактические цены подготовлены для учебного задания и являются синтетическими. Их метрики показывают поведение модели на этих примерах и не доказывают точность на независимом рынке.
