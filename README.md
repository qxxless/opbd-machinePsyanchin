# Рекомендательная система фильмов

Учебный проект по машинному обучению на MovieTweetings. Ноутбук включает исследование и очистку данных, сравнение рекомендаций, оценку на временной отложенной выборке, финальное переобучение и сохранение артефакта для API. MySQL хранит каталог, исходные оценки и новые оценки из приложения.

## Датасет

Использован фиксированный снимок MovieTweetings 200K из официального репозитория Simon Dooms. В каталоге data лежат только movies.dat и ratings.dat; users.dat намеренно не включён, потому что он связывает обезличенный ID с Twitter ID. Точная ревизия и хеши файлов указаны в data/SOURCE.txt. Лицензия репозитория приложена в data/LICENSE_MOVIETWEETINGS.txt.

Формат оценок: user_id, movie_id, rating, timestamp. Шкала источника — 0–10; ноль считается допустимой оценкой, не пропуском. ID фильма хранится строкой, чтобы не потерять ведущие нули IMDb.

## Структура

- notebooks/movie_recommendation_system.ipynb — EDA, обучение и оценка.
- models/recommender_bundle.joblib — финальная модель для API; создаётся ноутбуком.
- mysql/schema.sql — база и таблицы MySQL.
- scripts/load_mysql.py — загрузка MovieTweetings в MySQL.
- api/main.py — FastAPI: популярное, рекомендации по похожим фильмам, персональная выдача BPR/гибридом, поиск и сохранение оценок.
- app/streamlit_app.py — графическое приложение, работающее через API.

## Быстрый запуск

1. Установить MySQL 8.0 и Python 3.11 или новее. В MySQL Workbench открыть mysql/schema.sql и выполнить весь скрипт.
2. В корне проекта создать виртуальное окружение и установить зависимости:

   Windows PowerShell:

       py -m venv .venv
       .\.venv\Scripts\Activate.ps1
       pip install -r requirements.txt

3. Скопировать .env.example в .env, указать пароль локального MySQL и оставить имя базы movie_recommender.
4. Из корня проекта загрузить исходные данные:

       python scripts/load_mysql.py

5. Открыть ноутбук и запустить все ячейки сверху вниз. Он сохранит models/recommender_bundle.joblib.
6. В первом PowerShell окне запустить API:

       uvicorn api.main:app --reload

7. Во втором окне запустить приложение:

       streamlit run app/streamlit_app.py

Для показа можно запустить оба сервиса одним скриптом из корня проекта:

       .\.venv\Scripts\python.exe start_app.py

Скрипт проверит доступность MySQL и сохранённой модели, запустит API и Streamlit и откроет интерфейс в браузере. Для остановки нажмите Ctrl+C в этом окне.

Приложение откроется по адресу, который напечатает Streamlit. Документация API доступна по /docs, справка приложения и перечень методов — на вкладке «Справка».

## Проверка базы

После загрузки выполните в Workbench:

    USE movie_recommender;
    SELECT COUNT(*) FROM users;
    SELECT COUNT(*) FROM movies;
    SELECT COUNT(*) FROM ratings;

Загрузчик использует upsert, поэтому его можно запустить повторно без дублирования оценок. Оценка в приложении обновляет запись пары пользователь–фильм и сразу сохраняется в MySQL.

## Методика

Разбиение по времени делается отдельно для каждого пользователя: последние 20% оценок остаются в тесте. Фильтрация 10-core применяется только к обучающей части и оставляет пользователей и фильмы с достаточной историей для collaborative filtering. Для ранжирования релевантной считается оценка не ниже 7 из 10. Это учебная офлайн-оценка на одном датасете, а не гарантия качества на новых пользователях.

Notebook сравнивает Bayesian Popularity, user-user и item-item collaborative filtering, TF-IDF, BPR и ALS. Для прогноза рейтинга также сравниваются LightGBM на признаках истории и ансамбль ALS + LightGBM. Настройки BPR, LightGBM и веса гибрида выбираются на отдельной временной validation-части; финальный test используется только для итоговой оценки. Для численного прогноза выводятся MAE, RMSE и R², для списка рекомендаций — Precision@10, Recall@10, NDCG@10 и HitRate@10.

В текущем отчёте ансамбль 0,25 ALS + 0,75 LightGBM даёт RMSE около 1,39 и R² около 0,36 на фиксированном сэмпле из 1200 отложенных оценок. Гибрид BPR 0,80 + popularity 0,10 + content 0,10 достигает NDCG@10 около 0,116 на тестовой выборке; исходный popularity/content-гибрид — около 0,058. Проверенные настройки выбраны по validation. Это не доказывает глобальный оптимум: дальнейший рост возможен с новыми данными, описаниями фильмов или экспериментами на других временных периодах. Ограничения и полный список сравнений приведены в ноутбуке.
